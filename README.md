# Interview Practice

A study app for system design and algorithm knowledge, with 54 branching questions across food delivery, chat, and URL shortening, progressive architecture diagrams, and 60 recall cards. Daily reviews use FSRS, and each scenario family keeps its unfinished session when you switch. You can add private cards or back up your practice as JSON. Supabase supports Google sign-in and private progress sync with the migrations and variables in `.env.example`; public deployment is still in progress. With Node 24 and pnpm, run `pnpm install` and `pnpm dev`. Checks are `pnpm test`, `pnpm build`, and `pnpm test:e2e`.
