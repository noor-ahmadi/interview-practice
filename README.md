# Interview Practice

A study app for system design and algorithm knowledge, with two food-delivery starting variants, 18 branching questions, progressive architecture diagrams, and ten recall cards. Daily reviews use FSRS, and you can add private cards or back up your practice as JSON. Supabase supports Google sign-in and private progress sync when configured with the migrations and variables in `.env.example`. The question library and public deployment are still in progress. With Node 24 and pnpm, run `pnpm install` and `pnpm dev`; `pnpm test`, `pnpm build`, and `pnpm test:e2e` check the current slice.
