# Interview Practice

A study app for system design and algorithm knowledge, starting with a food-delivery scenario and a few branching follow-ups. The diagram grows when you reveal an answer, and notes and self-ratings stay in your browser. Spaced repetition, accounts, and a larger question bank are next. With Node 24 and pnpm, run `pnpm install` and `pnpm dev`; `pnpm test`, `pnpm build`, and `pnpm test:e2e` check the current slice.
